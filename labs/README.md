# Articulate Storyline 360 Masterclass — Labs

**Course code:** C1058
**Version:** v1.0 · 2 October 2026

Each lab is self-contained and includes an original BEGIN .story file, a completed END .story reference, a detailed guide and a preview. Work from a new copy of BEGIN; never overwrite the supplied baseline or END reference.

## Lab sequence

1. [Lab 01 — Replace Visuals and Establish a Theme](lab-01-replace-visuals-and-theme/README.md) — Replace supplied media and harmonise the project theme while preserving scene structure and navigation.
2. [Lab 02 — Populate the Storyboard with Course Content](lab-02-populate-storyboard-content/README.md) — Turn a skeletal template into a storyboard-aligned three-slide course overview using reusable project assets.
3. [Lab 03 — Curate and Replace Audience-Fit Media](lab-03-curate-and-replace-media/README.md) — Evaluate customer preferences, select a suitable visual style and replace project assets consistently.
4. [Lab 04 — Create and Govern an AI-Assisted Visual Variation](lab-04-ai-assisted-visual-variation/README.md) — Create an AI-assisted visual variation, evaluate it against the brief and retain transparent provenance evidence.
5. [Lab 05 — Add Narration and Closed Captions](lab-05-narration-and-captions/README.md) — Add and synchronise narration, captions and accessible playback controls without duplicating unnecessary on-screen text.
6. [Lab 06 — Build a Multi-Slide Audio and Caption System](lab-06-multi-slide-audio-accessibility/README.md) — Implement multiple audio/caption tracks consistently and validate timing, focus and playback behaviour across slides.
7. [Lab 07 — Build a Graded Question with Feedback](lab-07-graded-question-and-feedback/README.md) — Add a graded question with plausible distractors, feedback, scoring and accessible response behaviour.
8. [Lab 08 — Build a Multi-Question Quiz and Result Logic](lab-08-multi-question-quiz-results/README.md) — Create a multi-question quiz with single- and multiple-response items, feedback, result logic and retry behaviour.
9. [Lab 09 — Add a Summary, Review and Publish Plan](lab-09-summary-review-and-publish/README.md) — Create a useful summary slide, define review criteria and configure a publish plan aligned with channel, tracking and delivery frequency.
